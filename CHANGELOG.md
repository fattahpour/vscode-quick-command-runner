# Changelog

## [0.1.0] - 2026-06-11

### Added

- Commands view: configurable groups/commands, run/cancel with live status icons, search/filter, Favorites and Recent sections.
- History view: per-run records with sort, filter, clear, re-run, and log viewing.
- Per-command Output channels with open/clear actions and optional auto-open.
- Automatic detection and clipboard copy of file paths printed by commands.
- `${workspaceFolder}` substitution in `cwd`, `command`, `file`, `args`, and `env`.
- Configurable settings for auto-copy, notifications, cancel grace period, and history/recent limits.
